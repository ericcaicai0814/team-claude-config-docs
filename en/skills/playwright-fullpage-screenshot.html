playwright-fullpage-screenshot ​

FieldValue
Nameplaywright-fullpage-screenshot
Description使用 Playwright 截取網頁完整頁面截圖。當需要「截取整頁截圖」「全頁截圖」「fullPage screenshot」「網站截圖收集」「頁面截圖有重複 header」「sticky header 重複」時使用。解決 fullPage 截圖時 sticky/fixed 元素重複的問題。
Source Directoryskills/playwright-fullpage-screenshot/

Playwright Full-Page Screenshot Without Duplicate Headers ​

使用 setViewportSize 方法取代 fullPage: true，避免 sticky/fixed header 在截圖中重複出現。

問題 ​

Playwright 的 fullPage: true 截圖會將多個 viewport 高度的畫面拼接，導致：

  • Sticky header 在每個區塊重複出現
  • Fixed position 元素重複渲染
  • 頁面結構看起來異常

解決方案 ​

javascript
async (page) => {
  await page.goto(url, { waitUntil: 'load' });
  await page.waitForTimeout(3000);

  // 1. 捲動頁面觸發懶加載圖片
  const totalHeight = await page.evaluate(() => document.body.scrollHeight);
  const viewportHeight = await page.evaluate(() => window.innerHeight);
  for (let pos = 0; pos < totalHeight; pos += viewportHeight * 0.5) {
    await page.evaluate((y) => window.scrollTo(0, y), pos);
    await page.waitForTimeout(400);
  }

  // 2. 回到頂部
  await page.evaluate(() => window.scrollTo(0, 0));
  await page.waitForTimeout(2000);

  // 3. 等待所有圖片載入
  await page.evaluate(() => Promise.all(
    Array.from(document.images).map(img => {
      if (img.complete && img.naturalHeight > 0) return Promise.resolve();
      return new Promise(r => {
        img.onload = img.onerror = r;
        setTimeout(r, 5000);
      });
    })
  ));

  // 4. 計算實際內容高度
  const contentHeight = await page.evaluate(() => {
    const footer = document.querySelector('footer, [role="contentinfo"], [class*="footer"]');
    return footer
      ? Math.ceil(window.scrollY + footer.getBoundingClientRect().bottom)
      : document.body.scrollHeight;
  });
  const pageWidth = await page.evaluate(() =>
    Math.ceil(document.documentElement.clientWidth)
  );

  // 5. 設定 viewport 為完整內容高度 - 關鍵步驟！
  await page.setViewportSize({ width: pageWidth, height: contentHeight });
  await page.waitForTimeout(500);

  // 6. 普通截圖（不使用 fullPage）
  await page.screenshot({ path: 'output.png' });
}

原理 ​

方法行為sticky header
fullPage: true捲動拼接多張截圖❌ 重複出現
setViewportSize單一畫面渲染全頁✅ 只出現一次

額外技巧 ​

懶加載處理 ​

  • 先捲動整個頁面觸發圖片載入
  • 使用 img.onload Promise 確保載入完成

networkidle 超時處理 ​

javascript
// 如果 networkidle 超時，改用 load + 手動等待
await page.goto(url, { waitUntil: 'load' });
await page.waitForTimeout(3000);

記憶體注意事項 ​

  • 非常長的頁面（>10000px）可能消耗大量記憶體
  • 考慮分段截圖或降低解析度

適用情境 ​

  • 資訊架構文件的網站截圖收集
  • 視覺回歸測試
  • 網頁設計稿存檔
  • 競品分析截圖
