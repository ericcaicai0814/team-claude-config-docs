快速上手 ​

歡迎使用 Team Claude Config — 團隊共用的 Claude Code 配置知識庫。

Clone 後一鍵設定，快速獲得統一的開發環境。

安裝 ​

bash
git clone git@github.com:<org>/team-claude-config.git ~/project/team-claude-config
cd ~/project/team-claude-config
bash setup.sh

重啟 Claude Code 即可使用。

前置需求 ​

工具版本說明
Claude Codelatestnpm install -g @anthropic-ai/claude-code
Node.js18+hook scripts 需要
jqanypre-commit-check hook 需要

架構總覽 ​

本知識庫包含以下配置模組：

  • Agents — 18 個自動化代理，涵蓋架構設計、TDD、安全審查、重構等工作流
  • Skills — 44 個可重用技能模組，從 CI/CD 到前端設計到 API 模式
  • Rules — 14 個團隊規範，包含編碼風格、安全、測試、效能等
  • Commands — 47 個快捷指令，一鍵觸發複雜工作流
  • Hooks — 3 個自動化掛鉤腳本
  • Hookify Rules — 9 個安全防護規則，攔截危險操作

核心行為規範 ​

所有 Agent 遵循 CLAUDE.md 中定義的行為規則：

  1. Plan first, act later — 修改前必須提出計畫並等待確認
  2. Analysis ≠ 修改 — review 時只產出分析，不動檔案
  3. Commit 格式 — 繁體中文 Conventional Commits
  4. Agent Teams 指引 — teammate 不可編輯同一檔案、完成後必須回報

Agent 系列 ​

系列說明
ecc-*核心開發流程（架構、TDD、Code Review、安全、E2E）
evolve/配置生態審計（Memory、Agent、Skill、Hook、Rules）
ccg/輔助工具（日期、初始化、規劃、UI/UX 設計）

個人化覆寫 ​

  • settings.local.json — 覆寫 settings.json 設定（不被 git 追蹤）
  • 個人 Skills — 在 ~/.claude/skills/ 新增個人 skills
  • Auto Memory — 跨 session 保留偏好與脈絡

更新方式 ​

bash
cd ~/project/team-claude-config
git pull
bash setup.sh

setup.sh 是 idempotent 的——已存在的正確 symlinks 會被 skip，重複執行安全無虞。
